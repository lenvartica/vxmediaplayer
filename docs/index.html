Room to turn it up

A 0–300% volume control gives you extra range for quiet recordings. Output limits depend on your LibVLC build and audio hardware.

◈

Play just about anything

Powered by LibVLC for popular video, audio, and subtitle formats, including MP4, MKV, FLAC, WebM, and more.

◎

Private by design

No analytics or telemetry in the player. Your files and playback history stay on your device.

≋

Shape the sound

Fine-tune a 10-band equalizer with ready-made presets, playback speed, and subtitle timing controls.

▤

Keep your place

Build and filter a drag-and-drop queue, save M3U8 playlists, and revisit recently played files.

⌗

At home on your desktop

A dark, focused interface with keyboard shortcuts, picture-in-picture window mode, and adjustable subtitle timing.

Up and running in minutes

Get started.

Choose a ready-to-run release or launch from source. VxPlayer requires Python 3.11+ for source installs.

WindowsLinuxFrom source

Windows release

  1. Download VxPlayer.exe from the latest release.
  2. Run the executable. The Windows release includes the LibVLC runtime.
  3. Open a file or drag media into the player.

Run from source

            git clone https://github.com/lenvartica/vxmediaplayer.git
cd VxPlayer
python -m pip install -r requirements.txt
python src/main.py

Troubleshooting: If LibVLC cannot initialize, install VLC for your platform and ensure its runtime libraries and plugins are available. Linux builds require system LibVLC and Qt-compatible display libraries.
